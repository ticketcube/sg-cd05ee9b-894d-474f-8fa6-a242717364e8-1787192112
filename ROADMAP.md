## 🔄 How This Works

This roadmap is **automatically updated** by GitHub Actions whenever:
1. **Issues are created/updated** with the `requirement` label
2. **Status labels change** (status-backlog, status-todo, status-in-progress, status-done)
3. **Issues are closed** (automatically marked as Complete)
4. **Weekly schedule** runs (every Sunday at midnight UTC)
5. **Manual trigger** via GitHub Actions

### Automatic Project Board Sync
When you add a status label to an issue:
- `status-backlog` → Moves to **Backlog** column
- `status-todo` → Moves to **To Do** column
- `status-in-progress` → Moves to **In Progress** column
- `status-done` → Moves to **Done** column

The workflow automatically:
1. Detects the status label change
2. Finds the issue in your GitHub Project board
3. Moves it to the corresponding column
4. Leaves a comment confirming the move
